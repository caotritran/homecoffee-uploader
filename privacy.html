HomeCoffee Uploader

Privacy Policy

Last updated: November 7, 2026

Summary

HomeCoffee Uploader is a personal tool with a single user, the channel owner. It collects no data from anyone else, uses no analytics or ads, and sells or shares nothing.

Data the Service handles

  • TikTok authorization tokens (access token, refresh token, open ID) for the owner's account. They are stored only on the owner's own computer, in a file only the owner can read, and are used only to call TikTok's API.
  • Basic profile information (user.info.basic: display name and avatar), used only to confirm which account is connected.
  • Video files the owner chooses to upload. They are sent straight to TikTok and are not copied anywhere else.

What the Service does not do

  • It does not read other users' data, followers, messages or analytics.
  • It does not run a server database. These web pages are static and set no cookies.
  • It does not share data with third parties other than TikTok itself.

Authorization redirect page

After sign-in, TikTok sends the browser to callback.html on this site. That page shows the one-time authorization code in the browser so the owner can copy it. The page sends the code nowhere and does not store it.

Retention and deletion

Tokens are kept until the owner deletes them or revokes access. To revoke access, go to the TikTok app: Settings and privacy → Security → Manage app permissions.

Children

The Service is not directed at children and does not knowingly collect their data.
